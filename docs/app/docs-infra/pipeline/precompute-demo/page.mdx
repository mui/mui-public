# Precompute Demo

Use `precomputeDemo` to load and process demo source files without a factory wrapper. It recursively loads relative files, highlights source, applies configured transforms and enhancers, and collects external imports and dependencies.

## Basic usage

```ts
import { precomputeDemo } from '@mui/internal-docs-infra/pipeline/precomputeDemo';

const result = await precomputeDemo({
  entries: [
    {
      name: 'Default',
      url: new URL('./BasicButtons.tsx', import.meta.url).href,
    },
  ],
});
```

The returned `code` uses each entry name as a variant name. `externals` contains the merged package imports from every loaded file, and `dependencies` contains the unique source URLs for build-tool invalidation.

## Multiple variants

Provide one entry for each source variant:

```ts
const result = await precomputeDemo({
  entries: [
    { name: 'Default', url: new URL('./Default.tsx', import.meta.url).href },
    { name: 'Compact', url: new URL('./Compact.tsx', import.meta.url).href },
  ],
});
```

Use `namedExport` when an entry points to a named export. Use `fileName` only when it cannot be derived from the URL.

## Grammar selection

The file extension picks the grammar. The whole JavaScript family — `.js`, `.jsx`, `.ts`, `.tsx` — shares one grammar, so a `.js` entry holding JSX needs no configuration, and a file is highlighted identically to its TypeScript twin.

Set `language` when the extension picks no grammar of its own:

```ts
const result = await precomputeDemo({
  entries: [{ name: 'Default', url, language: 'jsx' }],
});
```

## Relative files

Files reached through relative imports are presented as siblings of the entry, whatever their position on disk, and their imports are rewritten to match. A demo importing `../../shared/data.ts` shows a `data.ts` file importable as `./data`, so a reader sees a self-contained folder rather than the demo's place in a repository. Each file keeps a `relativeUrl` pointing at its real location.

Supply your own `loadSource` if a project needs the resolved paths kept instead.

## Configuration

The default pipeline reads local files, recursively resolves relative imports, highlights source, and applies focus and emphasis markers. Override `loadSource`, `sourceParser`, `sourceTransformers`, or `sourceEnhancers` to replace individual stages.

```ts
const result = await precomputeDemo({
  entries,
  output: 'hast',
  maxDepth: 3,
  sourceTransformers: [myTransformer],
});
```

Set `includeDependencies` to `false` when source display does not need relative files. This option configures the default filesystem source loader. A custom `loadSource` owns its dependency behavior.
